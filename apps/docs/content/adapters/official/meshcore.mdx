## Quick start

Set the serial port path for your Companion Radio:

```bash
export MESHCORE_SERIAL_PORT=/dev/ttyACM0
```

Then register the adapter:

```typescript title="lib/bot.ts" lineNumbers
import { Chat } from "chat";
import { createMeshCoreAdapter } from "@chat-adapter/meshcore";
import { createMemoryState } from "@chat-adapter/state-memory";

export const bot = new Chat({
  userName: "mybot",
  adapters: {
    meshcore: createMeshCoreAdapter(),
  },
  state: createMemoryState(),
});

bot.onDirectMessage(async (thread, message) => {
  await thread.post(`You said: ${message.text}`);
});
```

MeshCore is not webhook based. The adapter opens the serial port during Chat initialization, syncs the radio clock, sends a flood advert, and drains waiting text messages into Chat SDK handlers.

## Thread IDs

Contact threads use the sender public-key prefix:

```text
meshcore:contact:010203040506
```

Channel threads use the MeshCore channel index:

```text
meshcore:channel:0
```
